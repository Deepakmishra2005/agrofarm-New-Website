AGROFARM INTERACTIVE MULTI-PAGE WEBSITE

Pages included:
index.html          Home
about.html          About
industry.html       Agriculture industry overview
challenges.html     Challenges
solutions.html      Solutions hub
weather.html        Weather planning demo (not a live forecast)
crop-guide.html     Interactive crop category tabs
soil.html           Soil observation form demo
market.html         Market dashboard with fictional sample prices
expert-advice.html  Question preparation form
buyer-connect.html  Sample produce listing form
how-it-works.html   Step-by-step journey
contact.html        Contact form

Shared files:
style.css           Responsive styling
script.js           Mobile menu, dropdown, search, tabs, demo forms, back-to-top and contact mailto action

Run locally:
Extract the ZIP and open index.html in Chrome, Edge, Firefox or Safari. Keep all files in the same folder.

Publish:
Upload every file in this folder to the root of a GitHub repository. Enable GitHub Pages from Settings > Pages > Deploy from a branch > main > /(root).

Important functionality notes:
- Navigation and every page CTA lead to a dedicated HTML page.
- Interactive forms are front-end demonstrations and do not save to a server.
- Contact form opens the visitor's configured email app.
- Weather tool is not connected to live forecast services.
- Market sample prices are fictional demonstration values, not current prices.
- Replace hello@agrofarm.example with a real project email before publishing.
